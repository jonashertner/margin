# Fonts

Paper Mono is bundled under SIL Open Font License 1.1. Keep `PAPER-MONO-OFL.txt` with the font when redistributing it. Source: https://github.com/paper-design/paper-mono, commit e6eaeceaef02e77e3db997711e07a16378de2bd7.

The serif stack falls back to Times New Roman and the platform serif face. For an optional local Timeless setup, obtain the original Regular and Bold files independently from https://www.dafont.com/timeless.font and review its terms. Install the original Regular and Bold faces with your operating system's font manager (Font Book on macOS), then reload the page. The public CSS uses local font lookup only; it does not request or download Timeless. Do not add those files to a public distribution without suitable permission.
